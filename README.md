# Estudos de Java
Repositório destinado aos estudos, exercícios e práticas desenvolvidos durante a disciplina Domain Driven Design Using Java, da graduação em Análise e Desenvolvimento de Sistemas na FIAP.

## Sobre a disciplina
A disciplina apresenta conceitos de Programação Orientada a Objetos, Java e Domain Driven Design (DDD), explorando a relação entre modelagem de domínio, arquitetura e desenvolvimento de software.

Durante os estudos, são abordados conceitos que permitem desenvolver soluções mais organizadas, reutilizáveis e com menor acoplamento, além da integração entre aplicações, banco de dados e API's.
